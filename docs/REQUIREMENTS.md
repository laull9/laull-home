# laull-home 需求点文档

## 书签系统

### 001 自动获取图标

新增书签时，如果用户没有主动指定图标：

1. 尝试获取页面声明的 favicon。
2. 尝试获取 apple-touch-icon。
3. 尝试 `/favicon.ico`。
4. 都失败时使用默认图标。

获取到的远程图标应缓存到服务器本地。

### 002 快速添加

主页必须提供明显的 `+` 按钮。

用户应能直接在主页完成：

- 输入标题；
- 输入 URL；
- 选择分组；
- 修改图标；
- 保存。

不要求进入独立设置页面。


## 搜索系统

### 001 URL 自动识别

输入：

github.com/openai

应直接打开 URL，而不是提交给搜索引擎。

### 002 搜索 Bang

支持：

!gh rust orm
!yt bun tutorial

Bang 必须允许用户自定义。


## 隐私

### 001 第三方请求

主页首次加载时，不应因为 favicon、背景或图标主动请求第三方服务。

远程资源应优先由服务器缓存。

### 002 Secret

微服务 Token 不允许发送到浏览器。


## UI

### 001 首页保持简洁

非编辑模式下不显示：

- 编辑按钮组；
- Widget resize handle；
- 调试信息；
- 管理入口。

### 002 编辑模式

用户进入 Edit Mode 后才允许：

- 拖动书签；
- 删除书签；
- 调整 Widget；
- 修改布局。

### 003 隐私空间

用户可以输入一个特别设置的密码进入隐私空间，隐私空间的内容不应被搜索引擎索引。
用户可以点击返回按钮退出隐私空间。

### 004 响应式UI

用户在不同设备上访问时，UI应自适应屏幕大小。
包括卡片布局按列数自适应，卡片大小自适应，Widget布局自适应等。
