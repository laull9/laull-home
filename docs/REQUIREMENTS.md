# laull-home 需求点文档

## 书签系统

### 001 自动获取图标

新增书签时，如果用户没有主动指定图标：

1. 尝试获取页面声明的 favicon。
2. 尝试获取 apple-touch-icon。
3. 尝试 `/favicon.ico`。
4. 都失败时使用默认图标。

获取到的远程图标应缓存到服务器本地。

### 002 快速添加

主页必须提供明显的 `+` 按钮。

用户应能直接在主页完成：

- 输入标题；
- 输入 URL；
- 选择分组；
- 修改图标；
- 保存。

不要求进入独立设置页面。


## 搜索系统

### 001 URL 自动识别

输入：

github.com/openai

应直接打开 URL，而不是提交给搜索引擎。

### 002 搜索 Bang

支持：

!gh rust orm
!yt bun tutorial

Bang 允许用户自定义。

### 003 搜索引擎选择与自定义

1. 搜索栏左侧展示当前选中的搜索引擎图标与下拉箭头。
2. 点击展开平铺面板，支持快速切换到其他搜索引擎。
3. 允许用户直接在搜索栏下拉面板中录入新搜索引擎，包括名称、带有 %s 的查询地址与快捷 Bang。


## 隐私

### 001 第三方请求

主页首次加载时，不因为 favicon、背景或图标主动请求第三方服务。

远程资源优先由服务器缓存。

### 002 Secret

微服务 Token 不发送到浏览器。


## UI

### 001 首页保持简洁

非编辑模式下不显示：

- 编辑按钮组；
- Widget resize handle；
- 调试信息；
- 管理入口。

### 002 编辑模式

用户进入编辑模式后才允许：

- 拖动书签；
- 删除书签；
- 调整 Widget；
- 修改布局。

### 003 隐私空间

用户输入独立密码进入隐私空间，隐私空间内容不被搜索引擎索引。
用户点击锁定按钮退出隐私空间并切回默认空间。

### 004 响应式UI

用户在不同设备上访问时，UI自适应屏幕大小。
包括卡片布局按列数自适应，卡片大小自适应，Widget布局自适应等。

### 005 去除顶部栏与悬浮操作

1. 移除首页固定顶栏，减少视觉遮挡。
2. 空间切换、编辑模式、设置与退出等低频操作收纳至右下角悬浮按钮中。
3. 点击悬浮按钮展开操作菜单，再次点击或点击空白处收起。

### 006 细粒度主题与自定义 CSS

1. 主题系统提供细粒度 CSS 变量，覆盖背景、卡片表面、悬停交互、多级文字、边框、圆角、阴影与模糊度。
2. 支持用户录入自定义 CSS 样式，服务端保存并在前端生效，用于个性化样式覆盖。

### 007 自动支持明暗模式

1. 支持跟随操作系统（prefers-color-scheme）实时切换浅色与深色表现。
2. 各主题预设同时兼顾白天与黑夜的色彩对比度，切换时无需刷新页面。

### 008 组件化桌面画布

1. 主页以组件为最小节点组织，取消固定的上下布局。
2. 搜索条、单图标书签、书签托盘、时钟天气、系统指标与微服务面板均抽象为组件节点。

### 009 微窗格锚点与固定排版

1. 采用约 96px 的微单元格作为响应式布局锚点，按断点自动计算 4 到 12 列。
2. 支持将组件固定（Pin）到特定网格位置，固定组件优先占位，其余组件围绕避让并按网格流自然平铺。

### 010 尺寸弹性与形态自适应

1. 容器宽度改变时，窗格单元具备微幅伸缩能力，整行空间不足时组件自动换行。
2. 组件内部通过容器查询感知自身空间，当窗格被压缩或尺寸降级时，自动折叠隐藏次要信息，简化界面形态。

### 011 组件库与抽屉式选择

1. 编辑模式下提供组件库抽屉，按类别收录丰富且大小不一的预设组件（1x1、2x1、2x2、4x1、4x2、4x4 等）。
2. 支持预览不同尺寸外观，支持点击自动追加或直接拖拽放置到目标网格单元。

### 012 组件就地内容编辑

1. 编辑模式下，用户可直接在组件当前位置编辑其内容与参数。
2. 便签类组件支持原地输入保存，书签类组件支持原地调整顺序与追加，配置类组件弹出就地浮层微调选项。

### 013 图标链接小书签

1. 占用 1x1 窗格，显示网站高清图标与简短标题，缺失图标时显示首字母胶囊。
2. 点击直接跳转目标链接，编辑模式下支持修改网址、替换图标或拖入相邻小书签自动合并为文件夹。

### 014 多形态文件夹组件

1. 支持 1x1、2x2 与 3x3 三种形态自由切换，内部书签数据无损保留。
2. 1x1 形态展示内部 4 格微型预览并在点击后弹出大浮层展开窗；2x2 与 3x3 形态在卡片表面直接展示排在前列的小书签，并提供翻页或快速过滤。

### 015 1xn 弹性搜索框组件

1. 固定占用 1 行高度，宽度支持按窗格跨度配置或自适应通栏。
2. 集成搜索引擎下拉切换、Bang 快捷指令与输入 URL 智能直接跳转。

### 016 高度自定义卡片与 API 接入

1. 提供 2x2、3x3、2x3 等形态，支持图表、文案、图片混合展示。
2. 支持在卡片内直接配置网络 API 地址、请求头、轮询间隔与 JSON 字段提取路径，通过后端安全代理读取并刷新数据。

### 017 预制卡片应用

1. 内置日历、时钟、天气、股票行情与指标可视化等开箱即用卡片。
2. 预制卡片支持配置时区、城市、股票代码与显示制式。

### 018 组件 UI 定制与独立 Scoped CSS

1. 支持自定义卡片背景半透度、毛玻璃模糊度、圆角、内间距与边框粗细。
2. 支持为组件单独编写独立 Scoped CSS，运行时添加独立选择器包裹，在编辑模式就地编辑实时预览，不污染全局样式。

### 019 组件复制与模板注册

1. 支持一键复制已有组件及其全部配置并在就近网格生成副本。
2. 支持将配置好的组件保存为自定义模板，并在组件库抽屉展示供后续反复拉取复用。

### 020 主题变量深度融合

1. 所有组件必须使用全局 Theme Tokens 构建底色、文字、边框与高亮。
2. 系统在明暗模式或主题变更时，组件各级色彩与效果同步平滑过渡。

### 021 同尺寸组件叠放

1. 支持将同尺寸组件相互拖拽堆叠，形成多层叠放卡片池。
2. 浏览模式下支持使用鼠标滚轮、双指滑动或手指上下扫动轮播切换，展示层级圆点指示器。

### 022 多端布局同步与降级

1. 支持桌面端与移动端保存独立断点坐标。
2. 支持移动端流式降级模式，按照桌面端阅读顺序自动流动排版，避免小屏错位。

### 023 后台标签页休眠与唤醒

1. 页面切入后台时挂起所有卡片的 API 定时轮询，节约系统资源。
2. 页面重新切回前台时触发静默补拉，刷新已过期数据。

### 024 键盘盲操与全局快捷跳转

1. 支持按下 / 键快速聚焦搜索栏。
2. 支持按住 Alt 或 Option 键显示数字角标（1 到 9）并快速直达前 9 个固定应用。
3. 支持桌面敲击字符即时过滤书签。

### 025 单卡片配置代码串导入导出

1. 支持将单卡片的配置、API 规则与独立 CSS 序列化导出为 Base64 文本代码串。
2. 支持粘贴配置代码串并在画布中直接实例化生成全新组件卡片。

### 026 三层 Token 架构与组件局部覆盖

1. 变量体系按原始基准值、全局语义变量与组件局部变量分层管理。
2. 组件默认继承全局语义变量，并支持在局部独立覆盖局部变量，不影响其他组件。

### 027 玻璃质感与色彩解耦调节

1. 支持独立配置卡片表面不透明度（50% 到 100%）。
2. 支持独立配置卡片磨砂模糊度（0px 到 30px）。

### 028 种子色推导主题与主题代码串

1. 支持根据单个主色自动生成满足 WCAG AA 对比度的明暗双模预设变量。
2. 支持将当前主题配置导出为轻量 JSON 代码串，并支持粘贴导入。

### 029 壁纸防冲突滤镜

1. 背景层支持 0% 到 80% 动态暗化遮罩调节。
2. 背景层支持 0px 到 24px 高斯模糊调节，消除壁纸细节对组件文字的干扰。


## MCP 协议支持

### 030 MCP 鉴权密钥生成与单向刷新

1. 用户在设置界面生成专属唯一的 MCP 访问密钥，数据库仅保存其 SHA-256 哈希值。
2. 密钥仅在生成或刷新时弹窗展示一次完整明文，后续界面仅展示末尾 4 位字符掩码。
3. 遗忘密钥后只能执行单向刷新，旧密钥立即作废失效。

### 031 页面级 CSS 与主题的 MCP 操控

1. MCP 客户端支持读取当前主题标识、三层 Token、壁纸滤镜及自定义 CSS。
2. MCP 客户端支持写入并覆盖全局自定义 CSS，并在安全范围内校验规则。

### 032 组件生命周期与独立 Scoped CSS 的 MCP 操控

1. MCP 客户端支持列出、读取、添加、修改、复制与删除桌面组件。
2. MCP 客户端支持为特定组件写入或修改独立 Scoped CSS，限制在组件选择器内生效。

### 033 桌面整体排布与窗格锚点的 MCP 操控

1. MCP 客户端支持读取指定断点下的组件窗格坐标矩阵。
2. MCP 客户端支持平移、调整尺寸跨度、锁定固定锚点与批量重排整页组件。

### 034 MCP 变更的浏览器实时热重载

1. 服务端在 MCP 执行成功写操作后，立即向浏览器广播 SSE 事件。
2. 浏览器端捕获事件后自动重新拉取数据并局部重绘，无需手动刷新页面。
