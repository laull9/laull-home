# laull-home 需求点文档

## 书签系统

### 001 自动获取图标

新增书签时，如果用户没有主动指定图标：

1. 尝试获取页面声明的 favicon。
2. 尝试获取 apple-touch-icon。
3. 尝试 `/favicon.ico`。
4. 都失败时使用默认图标。

获取到的远程图标应缓存到服务器本地。

### 002 快速添加

主页必须提供明显的 `+` 按钮。

用户应能直接在主页完成：

- 输入标题；
- 输入 URL；
- 选择分组；
- 修改图标；
- 保存。

不要求进入独立设置页面。


## 搜索系统

### 001 URL 自动识别

输入：

github.com/openai

应直接打开 URL，而不是提交给搜索引擎。

### 002 搜索 Bang

支持：

!gh rust orm
!yt bun tutorial

Bang 允许用户自定义。

### 003 搜索引擎选择与自定义

1. 搜索栏左侧展示当前选中的搜索引擎图标与下拉箭头。
2. 点击展开平铺面板，支持快速切换到其他搜索引擎。
3. 允许用户直接在搜索栏下拉面板中录入新搜索引擎，包括名称、带有 %s 的查询地址与快捷 Bang。


## 隐私

### 001 第三方请求

主页首次加载时，不因为 favicon、背景或图标主动请求第三方服务。

远程资源优先由服务器缓存。

### 002 Secret

微服务 Token 不发送到浏览器。


## UI

### 001 首页保持简洁

非编辑模式下不显示：

- 编辑按钮组；
- Widget resize handle；
- 调试信息；
- 管理入口。

### 002 编辑模式

用户进入编辑模式后才允许：

- 拖动书签；
- 删除书签；
- 调整 Widget；
- 修改布局。

### 003 隐私空间

用户输入独立密码进入隐私空间，隐私空间内容不被搜索引擎索引。
用户点击锁定按钮退出隐私空间并切回默认空间。

### 004 响应式UI

用户在不同设备上访问时，UI自适应屏幕大小。
包括卡片布局按列数自适应，卡片大小自适应，Widget布局自适应等。

### 005 去除顶部栏与悬浮操作

1. 移除首页固定顶栏，减少视觉遮挡。
2. 空间切换、编辑模式、设置与退出等低频操作收纳至右下角悬浮按钮中。
3. 点击悬浮按钮展开操作菜单，再次点击或点击空白处收起。

### 006 细粒度主题与自定义 CSS

1. 主题系统提供细粒度 CSS 变量，覆盖背景、卡片表面、悬停交互、多级文字、边框、圆角、阴影与模糊度。
2. 支持用户录入自定义 CSS 样式，服务端保存并在前端生效，用于个性化样式覆盖。

### 007 自动支持明暗模式

1. 支持跟随操作系统（prefers-color-scheme）实时切换浅色与深色表现。
2. 各主题预设同时兼顾白天与黑夜的色彩对比度，切换时无需刷新页面。

### 008 组件化桌面画布

1. 主页以组件为最小节点组织，取消固定的上下布局。
2. 搜索条、单图标书签、书签托盘、时钟天气、系统指标与微服务面板均抽象为组件节点。

### 009 微窗格锚点与固定排版

1. 采用约 96px 的微单元格作为响应式布局锚点，按断点自动计算 4 到 12 列。
2. 支持将组件固定（Pin）到特定网格位置，固定组件优先占位，其余组件围绕避让并按网格流自然平铺。

### 010 尺寸弹性与形态自适应

1. 容器宽度改变时，窗格单元具备微幅伸缩能力，整行空间不足时组件自动换行。
2. 组件内部通过容器查询感知自身空间，当窗格被压缩或尺寸降级时，自动折叠隐藏次要信息，简化界面形态。

### 011 组件库与抽屉式选择

1. 编辑模式下提供组件库抽屉，按类别收录丰富且大小不一的预设组件（1x1、2x1、2x2、4x1、4x2、4x4 等）。
2. 支持预览不同尺寸外观，支持点击自动追加或直接拖拽放置到目标网格单元。

### 012 组件就地内容编辑

1. 编辑模式下，用户可直接在组件当前位置编辑其内容与参数。
2. 便签类组件支持原地输入保存，书签类组件支持原地调整顺序与追加，配置类组件弹出就地浮层微调选项。
