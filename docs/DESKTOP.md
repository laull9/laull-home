# 组件桌面与主题

主页通过编辑模式进入布局设置。组件库提供搜索、图标书签、书签文件夹、便签、时钟和日历。组件支持复制、空间内模板复用，以及带版本的 Base64 配置导入导出。书签与分组管理保留原有入口，组件引用书签数据，不重复保存网址。

## 布局与保存

画布使用 96px 行高，桌面、便携本、平板和手机分别使用 12、8、6、4 列。固定组件优先占位，流式组件依顺序填充完整空位。发生冲突时向后寻找可容纳的矩形，避免组件相互覆盖。窄屏未保存独立坐标时使用流式降级。

编辑模式直接拖动整个组件，鼠标和触屏共用指针事件。拖动超过 6px 才开始移动，轻点仍执行原有点击，Esc 可取消。组件跟随指针，落点矩形使用保存时的避让算法，松开后落在预览位置。搜索组件外层无背景、边框或阴影，网格只负责定位。配置窗口也可通过数字输入修改位置、跨度和固定状态。坐标从 0 开始。搜索组件固定为一行。叠放组件必须在所有断点拥有相同尺寸，支持按钮、滚轮和触屏手势轮换。

编辑保留内存草稿，点击“保存布局”统一提交。失败保留草稿；版本冲突要求主动重读，不能静默覆盖另一设备。离开页面或切换空间前检查未保存内容。便签输入属于布局草稿，需要一起保存。

desktops 表每个空间保留一条当前快照，包含节点、模板和四种断点。revision 通过事务比较并递增。空间删除时级联清理。每份快照最多 120 个节点、40 个模板、512 KiB；不保存历史版本，容量不会随编辑次数增长。后续需要历史恢复时应另设配额与保留期。

首次读取旧主页时将原分组映射为文件夹，首次保存才写入快照。书签原始数据保持独立。

## 主题

主题包含三层变量：

| 层次 | 内容 |
| --- | --- |
| 原始参数 | 种子色、不透明度、模糊、圆角、网格间距 |
| 全局语义 | 背景、表面、正文、次要文字、强调色、边框 |
| 组件局部 | 表面、文字、不透明度、模糊、圆角、内间距、边框宽度 |

预设主题继续可用。开启种子色时生成浅色和深色颜色，按钮前景按对比度选择黑或白。生成色的正文与按钮文本通过 AA 对比度测试；手工覆盖颜色后由用户控制配色，不能保证所有自定义组合的对比度。

壁纸暗化与模糊作用于独立背景层，范围分别为 0–80% 和 0–24px。卡片不透明度为 50–100%，模糊为 0–30px。跟随系统时实时响应明暗变化，组件局部颜色覆盖保留。

主题 JSON 代码串包含版本 1，导入经过完整字段和范围校验。编辑器实时预览结构化参数，保存与原有设置共用版本锁；离开未保存的编辑页恢复服务端设置。

全局及组件 CSS 接受简单元素、类选择器和展示属性，逐个选择器添加作用域。禁止网络资源、脚本、转义、注释、嵌套规则与定位逃逸。全局 body、html、:root 映射到应用根。组件 CSS 保存前校验，不支持任意第三方样式表。

## 授权和生命周期

画布接口要求登录。隐私空间还要求有效的独立空间授权，普通空间不能引用隐私空间的书签或分组。模板随空间保存，不能跨空间读取。客户端不将画布写入 localStorage 或 IndexedDB。

书签重读先清空旧内容，并用请求版本丢弃迟到响应。时钟在页面隐藏时停止更新时间；恢复可见时立即校准。当前六类组件不会请求外部天气、行情或网络 API。

## 当前边界

天气、股票、网络 API 卡片和私人微服务面板依赖受控 Integration 代理，仍属于后续服务模块。MCP、SSE、主题包资源上传也未在本轮实现。

当前支持显式同尺寸叠放和书签拖拽自动合并成文件夹。文件夹内拖拽排序、组件局部 CSS 输入过程实时预览仍未实现。组件库提供类型和尺寸选择，尚无每种尺寸的独立缩略预览。

## 验证

执行 bun run check。新增行为用例检查画布读写、版本冲突、原子失败、空间授权、来源校验、无效引用、容量边界、布局避让、种子色对比度与 CSS 限制。数据库均使用内存，未读取私人配置或调用外部服务。

浏览器验收已覆盖整块拖动、吸附预览、保存后的服务端坐标、Esc 取消、对话框焦点约束、图标加载以及 390px 窄屏无横向溢出。图标验收使用隔离数据库中的本地图片，不访问私人书签。
