# 外观与快捷编辑

设置采用侧栏导航与独立分页，内容左对齐。手机上导航换行，表单保持单列。


主题风格与主题色彻底解耦。风格核心提供「现代」与「像素」两套体系，其中「现代」全面适配磨砂毛玻璃透光、微光边框、柔和多层弥散阴影与平滑大圆角，「像素」保持硬边框、硬阶梯投影与直角排版。主题色独立配置，提供经典蓝、海盐蓝、石墨灰、松林绿、莓果紫、靛夜蓝、黄铜金、樱粉色等预设色盘及自定义拾色器，在双模下正文与强调色对比度均符合 WCAG AA。历史旧主题平滑归入现代风格并自动保留原配色。

设计复核：主题区别不能仅靠强调色。预设同时改变表面、背景、形状与密度，选择预设时清除结构化颜色覆盖和自定义 CSS，让切换立即可见。壁纸保留用户选择。设置不堆叠营销说明；主题预览承担展示工作。

外观与壁纸停止输入 500ms 后自动保存；请求串行，保存期间的新输入继续排队，旧响应不覆盖新预览。失败保留草稿并提供重试，版本冲突要求重新读取。离开页面前等待保存，失败阻止离开。账号密码等安全操作仍显式确认。

画布与组件的右键菜单提供当前空间布局、添加图标导航、组件配置和书签编辑，新增书签后创建引用它的图标组件并打开配置。表单保留浏览器原生菜单。Esc、点击外部和滚动关闭菜单，支持键盘方向键。
